# DBCP: Dual-Branch Convolution with Pixelwise Vision Transformer

## Area: Hyperspectral Image Classification

### Hyperspectral image (HSI) classification deals with images and presents challenges due to high dimensionality, mixed pixels, and noise. Unlike traditional image classification tasks where each image is associated with one class, in HSI classification, each pixel within one single image is labeled with a specific class. This leads to complex data with high spectralandspatialvariability, which makes accurate classification difficult. Additionally, the high dimensionality increases computational complexity while mixed pixels and noise can further degrade classification per formance. To address these challenges, this research proposes a hybrid model Dual-Branch Convolution with Pixelwise Vision Transformer (DBCP). The DBCP model adopts a dual-path strategy to synergize local spectral-spatial information extraction with global contextual modeling. The CNN branch uses a 3D-CNN for non-linear dimensionality reduction, followed by a Separate Groupwise Convolution (SGC) block. The SGC block employs multi-scale kernels to capture spectral-spatial features. On the other hand, the Pixelwise Vision Transformer (ViT) branch treats individual pixels as patches, which uses a multi-head self-attention mechanism to model long-range spatial dependencies. By aggregating information from surrounding pixels, the ViT branch provides robust contextual cues to resolve the classification of mixed pixels at class boundaries. Furthermore, a Squeeze-and-Excitation (SE) block is integrated to recalibrate channel importance, allowing the network to focus on the most relevant spectral-spatial infor mation. Experimental results show that the proposed DBCP model outperforms state-of-the-art methods across all benchmark datasets in this study, including Indian Pines, Botswana, Salinas, and WHU-Hi-LongKou. Specifically, it achieves over 99% Overall Accuracy (OA) on both the Salinas and Botswana datasets, while also delivering strong results on Indian Pines and WHU-Hi-LongKou, with OA values of 97.23% and 98.68%, respectively.
